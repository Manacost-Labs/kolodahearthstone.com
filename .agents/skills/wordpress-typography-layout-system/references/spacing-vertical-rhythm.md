# Spacing and vertical rhythm

Use the approved spacing scale: 4, 8, 12, 16, 24, 32, 48, and 64 px. Select tokens by relationship—inline, control, component, section, or page—not by the nearest attractive number.

Visual rhythm comes from repeated alignment and predictable density. Keep tighter gaps inside a semantic group and larger gaps between groups. Let heading margins follow the reading structure; avoid stacked child/parent margins that accidentally double spacing.

Test dense and sparse content, wrapped labels, multi-line titles, form errors, captions, ads, missing images, and admin notices. Responsive layouts may change which scale step is used, but should not introduce a second mobile-only spacing scale.
