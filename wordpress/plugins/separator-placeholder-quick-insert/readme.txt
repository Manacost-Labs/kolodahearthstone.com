Быстрая вставка разделителей и заглушек прямо из редактора Gutenberg.

== Description ==

Плагин добавляет в меню редактора (⋮ → «Разделители и заглушки») кнопку, которая открывает модальное окно с двумя вкладками: «Разделители» и «Заглушки». Клик по картинке вставляет её как блок «Изображение» в позицию курсора.

Управление наборами — в **Инструменты → Разделители и заглушки**: для каждой вкладки отдельный набор изображений, выбираемых из медиатеки.

== Installation ==

1. Скопируйте папку плагина в `wp-content/plugins/`.
2. Активируйте «Separator & Placeholder Quick Insert» в админке.
3. Перейдите в **Инструменты → Разделители и заглушки** и добавьте изображения.
4. Откройте редактор статьи — кнопка появится в меню «Дополнительно» (⋮).
