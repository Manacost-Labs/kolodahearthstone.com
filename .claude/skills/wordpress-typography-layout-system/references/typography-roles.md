# Typography roles

Define roles before selectors: utility/meta, navigation, body, lead, caption, card title, section title, article title, display/hero, label, button, form control, code, and numeric/stat. Each role owns family, size range, weight, line height, letter spacing, wrapping, and maximum measure.

Use hierarchy sparingly. Body text and article titles deserve the clearest contrast; metadata should be quieter without becoming too small. Test every role with real Cyrillic, long titles, dates, author names, deck codes, and mixed Latin/Cyrillic text.

Do not create a new role to justify a one-off value. Reuse a semantic role or document the user need as a deliberate exception in the visual-system contract.
