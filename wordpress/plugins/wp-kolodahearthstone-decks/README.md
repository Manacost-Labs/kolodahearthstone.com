# KolodaHeartstone: Decks

Плагин для управления колодами Hearthstone в WordPress.

## Возможности

- ✅ Custom post type для колод Hearthstone
- ✅ Поля: Заголовок, Код колоды, Изображение
- ✅ Шорткоды для отображения колод
- ✅ Каждая колода имеет свой ID и отдельную страницу
- ✅ Красивый дизайн в бежевых тонах
- ✅ Адаптивная верстка для мобильных устройств

## Установка

1. Скопируйте папку `wp-kolodahearthstone-decks` в директорию `/wp-content/plugins/`
2. Активируйте плагин в админ-панели WordPress

## Использование

### Создание колоды

1. Перейдите в меню **Колоды HS** → **Добавить колоду**
2. Заполните:
   - **Заголовок** - название колоды
   - **Изображение** - установите миниатюру (Featured Image)
   - **Код колоды** - вставьте код колоды из Hearthstone
3. Сохраните колоду

### Шорткоды

#### Отображение одной колоды

```
[hs_deck id="123"]
```

Где `123` - это ID колоды (можно найти в админ-панели в списке колод).

#### Отображение списка колод

```
[hs_decks count="12" columns="2"]
```

Параметры:
- `count` - количество колод для отображения (по умолчанию: 12)
- `columns` - количество колонок в сетке (по умолчанию: 2, максимум: 4)

### Просмотр шорткодов в админ-панели

1. В списке колод есть колонка **Шорткод** - там можно скопировать шорткод для каждой колоды
2. При редактировании колоды в боковой панели есть блок **Шорткоды** с готовым шорткодом

## Функции

- Каждая колода имеет уникальный ID
- Каждая колода имеет свою отдельную страницу (URL: `/hs_deck/название-колоды/`)
- Кнопка "Скопировать код" для быстрого копирования кода колоды
- Красивый дизайн карточек в бежевых тонах
- Адаптивная верстка для всех устройств

## Технические детали

- Custom post type: `hs_deck`
- Мета-поле для кода колоды: `_hs_deck_code`
- Изображение хранится как Featured Image (миниатюра поста)
