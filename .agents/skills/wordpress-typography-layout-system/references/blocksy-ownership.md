# Blocksy ownership map

Prefer Blocksy Customizer and `theme.json` for stable presentation settings. Use the child theme for scoped CSS/templates and a first-party plugin for behavior, integrations, or data. Never edit the Blocksy parent or generated dynamic CSS.

Verify header/footer builder placements, content container widths, typography, sidebars, and responsive controls at the contract viewports. Record the owning setting before changing it so a Blocksy update can be reviewed safely.
