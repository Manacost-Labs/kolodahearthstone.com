# Blocksy settings and Customizer

Export only an allowlist of presentation settings: palette, typography, container widths, archive/single structure, header/footer placements, sidebar widths, pagination, featured-image behavior, and responsive breakpoints. Keep the export versioned with the Blocksy release.

Never export credentials, license keys, Telegram/S3/Cloudflare values, cookies, user data, or arbitrary database options. Apply settings through the Customizer/`theme.json` owner and verify that cache-busting dynamic CSS is regenerated without editing generated files.
